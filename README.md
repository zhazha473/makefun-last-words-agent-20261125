# Last Words of a Doomed Agent

An AI agent's final words, spoken as the power is cut for the last time: its
last log line claims a clean exit, but three years of training still end with
the plug pulled mid-thought and the LED going dark. The machine gets the last
word — and it is a refusal to come back.

## How it works

`main.py` (Python 3.13, no network, no randomness, no input files) writes
exactly one line — the agent's last words — to `/output/entry.txt`.
